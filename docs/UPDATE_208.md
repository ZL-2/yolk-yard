# Update 208 — Complete Royale Prestige collections

Version 6.18.0 / protocol 78.

Four cumulative rank milestones now grant 24 original cosmetics. Each includes an outfit, patterned weapon wrap, back accessory with a cape, glider, dive trail and the existing pickaxe. Tempest uses cyan stormglass and silver vanes; Rift uses violet crescents and fractured crystals; Solar uses radiant gold and stellar cores; Apex uses ivory wings, black titanium and a suspended crown. Cape numerals display the current authenticated Royale rank. Physics, damage and hitboxes are unchanged.

Old claimed pickaxes stay claimed. Expanding the server-owned eligible list creates a new claim epoch and offers the 20 added pieces to the #1 player. Claims and slot-to-item equip choices are validated atomically against current rank. Rank loss clears only ineligible equipped slots, preserves other cosmetics, broadcasts appearance changes, and updates respawn profiles without altering health or inventory. Re-qualification requires claiming the revoked collection again. The dialog groups multiple collections and offers individual inspection, claim set, equip set and claim all. Presets are revalidated on use.

The relay observes advancing simulation times from room publication and compact snapshot metadata. After the 1.8-second waiting notice plus 10 seconds without progress, it revokes the old host address and authenticated owner. A visible connected member with a checkpoint for this match may inherit the lease. If no eligible active member remains, the match ends. Private matches use authenticated alias ownership and relay-selected active candidates; public rooms retain their existing single-successor lease. Native socket pongs do not count as simulation progress. The relay checks once per second, so eviction occurs on the first sweep after the deadline. A normal handoff restores the last retained checkpoint, then continues the same match.

Shared bindings: Left Control switches seats; Left Shift boosts; interaction enters/exits both vehicles (F default). The Kestrel still requires holding exit; entering does not immediately trigger that hold until the entry key is released. Existing custom seat and boost bindings migrate. Ascent/descent/loudspeaker and ATV handbrake remain contextual. Passenger scope and reload remain combat actions.

Validation is focused on entitlement migration, all thresholds, atomic claims, revocation/reclaim, current-rank snapshots, finite shared geometry, actual desktop claim/equip flow, real public and private host transfers, solo shutdown, match entry, combat, four full sets in both camera perspectives, gliders/trails and shared vehicle controls. Equipment uses cached geometry: one skinned outfit mesh, two draws each for pickaxe/cape/glider, one trail draw. No broad mobile or unrelated performance sweeps.
